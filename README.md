# 🤖 Translation Bot with Gemini AI

A dedicated Telegram userbot designed to translate and verify messages from **Khmer to English**. This project was custom-built as a personalized utility for my friend **Luka**.

> ⚠️ **IMPORTANT NOTICE:** This repository is intended strictly for personal use and is not designed for public deployment. If you wish to use it, you must modify the codebase yourself to fit your own environment. 
> 
> **Note on AI Integration:** This project is built to integrate with **Gemini AI**, but this section is currently unavailable and is **coming soon**.

---

## ✨ Features

- 🇰🇭 ➡️ 🇬🇧 **Smart Khmer Translation:** Instantly converts incoming Khmer script into natural, grammatically correct English.
- 🧠 **Gemini AI Integration:** *(Coming Soon)* Designed to leverage Google's Gemini API logic to interpret tone, slang, and contextual nuances.
- 💬 **Friend-Centric Workflow:** Automatically analyzes and tracks chat inputs to make communication smooth and fast.
- ⚡ **Asynchronous Core:** Powered by the Telethon framework for lightning-fast message processing.

---

## 📋 Prerequisites & Core Stack

- **Python 3.9** or newer
- **Telethon Client Library** (for interacting with the Telegram API)
- **Google GenAI / Gemini Library** (for processing natural language translation)

---

## 🚀 Getting Started

1. **Clone the Project Repository**:
   ```bash
   git clone https://github.com
   cd Translation_Bot_With_Gemini_AI
   ```

2. **Set Up a Local Environment**:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate  # On Windows use: .venv\Scripts\activate
   ```

3. **Install Core Requirements**:
   ```bash
   pip install telethon google-generativeai
   ```

4. **Launch the Bot**:
   ```bash
   python main.py
   ```
